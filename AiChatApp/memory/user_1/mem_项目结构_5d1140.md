1. NetYamlForge 项目中包含 photo-vault 子项目，该子项目具有 entities、pages 和 views 目录，用于照片实体定义和 Razor 视图模板。
2. 项目中包含名为 photos 的动态实体表，其访问路径为 /photo-vault/DynamicEntity/Index?entity=photos。
3. NetYamlForge 项目的页面（如“导入任务历史”）由 NetYamlForge/projects 目录下的 YAML 配置文件（例如 PhotoImport.yaml）定义。
4. 项目根目录下包含启动（start）、停止（stop）、重启（restart）脚本以及启动日志 startup.log，用于管理应用的生命周期与监控运行状态。
